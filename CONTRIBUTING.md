# Contributing to HyperSharp

Thanks for your interest in contributing! I appreciate any help, since being a solo developer is difficult, whether it's bug reports, new features, documentation or code contributions.

## Getting started

1. **Fork** the repository and clone your fork locally
2. Make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.
3. Build and run tests to make sure everything works:
   ``` bash
   dotnet build
   dotnet run
   ```
4. Create a new branch for your changes:
   ``` bash
   git checkout -b my-branch
   ```

## Guidelines
- Please follow the existing code style and naming conventions. Use consistent indentation and comment your code clearly.
- Write clear and concise commit messages describing your changes, e.g., "Fix a bunch of XML summaries for clarity".  (I know, this one can be challenging...)
- Open P.Rs against the `main` branch with a clear description of your changes.
- Add or update XML docs if your changes affect public APIs or usage.

### Every contribution matters.
- Whether it's a big or a small change, it's valuable and appreciated.
- Contributions are reviewed carefully, but please don't take it personally if your changes can't be merged. I just want to keep the project consistent and focused.


>Thank you for helping improve HyperSharp!
